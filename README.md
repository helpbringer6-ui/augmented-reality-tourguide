# Augmented Reality Tour Guide

## Projektbeschreibung
Diese Anwendung nutzt Augmented Reality, um Touristen einen einzigartigen und informativen Besuch in historischen Städten zu ermöglichen. Benutzer können ihre Smartphones oder AR-Brillen verwenden, um Informationen über berühmte Sehenswürdigkeiten, historische Ereignisse und interessante Fakten in Echtzeit zu sehen.

## Funktionen
- **Interaktive Karten**: Benutzer können durch die Stadt navigieren und erhalten AR-Überlagerungen mit Informationen über die Umgebung.
- **Geschichten und Anekdoten**: Jede Sehenswürdigkeit wird von interessanten Geschichten begleitet, die die Benutzer in die Vergangenheit entführen.
- **Mehrsprachige Unterstützung**: Die Anwendung bietet Inhalte in verschiedenen Sprachen an, um internationale Touristen willkommen zu heißen.
- **Benutzerbewertungen**: Touristen können die Sehenswürdigkeiten bewerten und ihre Erfahrungen teilen.
- **Empfehlungssystem**: Basierend auf Benutzerinteressen schlägt die Anwendung weitere Orte vor, die besucht werden könnten.

## Installation
1. Klonen Sie das Repository: `git clone https://github.com/IhrBenutzername/augmented-reality-tourguide.git`
2. Installieren Sie die Abhängigkeiten mit `npm install` oder `yarn install`.
3. Starten Sie die Anwendung mit `npm start` oder `yarn start`.

## Technologiestack
- React Native für die mobile Anwendung
- ARKit oder ARCore für Augmented Reality
- Node.js für den Backend-Server
